## Running Locally

### Prerequisites

- Node.js 18 or later
- npm

### Installation

```bash
git clone https://github.com/AmanKumar2202/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Open the local address displayed by Vite in your browser.

## Available Scripts

```bash
npm run dev
```

Starts the development server.

```bash
npm run build
```

Creates an optimized production build.

```bash
npm run lint
```

Runs ESLint across the project.

```bash
npm run typecheck
```

Checks the TypeScript source without generating output.
